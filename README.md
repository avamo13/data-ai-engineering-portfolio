# Data, AI & Engineering Portfolio

A collection of technical projects, experiments, and case studies across **data science, machine learning, artificial intelligence, data engineering, and software development**.

This repository serves as a growing portfolio of hands-on work focused on applying technical concepts to practical problems, exploring different technologies, and building reproducible end-to-end solutions.


## Philosophy

The goal of these projects is not only to produce working implementations, but to understand and document the decisions behind them.

Projects may therefore include:

* problem formulation;
* exploratory analysis;
* theoretical considerations;
* implementation choices;
* alternative approaches;
* validation strategies;
* performance evaluation;
* error analysis;
* limitations;
* possible improvements.

Whenever appropriate, projects are designed to be reproducible and use publicly available datasets or resources.
